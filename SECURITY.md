# Politique de sécurité

## Signaler une vulnérabilité

Merci de ne **pas** ouvrir d'issue publique pour signaler une faille de sécurité. Contacter les
mainteneurs du dépôt directement (voir les informations de contact du dépôt Git hébergé) en
décrivant :

- la nature de la vulnérabilité,
- les étapes pour la reproduire,
- l'impact potentiel.

Un correctif sera priorisé en fonction de la gravité. Voir aussi [`docs/security.md`](docs/security.md)
pour le détail des mesures de sécurité déjà en place (authentification, RGPD, protections réseau).

## Versions supportées

Tant que le projet est en version `0.x`, seule la dernière version de la branche `main` est
supportée.
